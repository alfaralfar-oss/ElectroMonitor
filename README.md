# ElectroMonitor v0.2
Fitur: input V/A/durasi, hitung daya dan energi, tarif dan biaya, grafik, filter tanggal, export CSV, penyimpanan LocalStorage, manifest dan service worker PWA.

Deploy melalui hosting HTTPS agar service worker dan instalasi PWA aktif. Data versi ini masih tersimpan di browser/perangkat masing-masing, belum database online.

Model perhitungan dasar P=V×I dan E=P×jam/1000. Untuk daya aktif AC, faktor daya perlu diperhitungkan. Gunakan data simulasi untuk belajar; jangan melakukan pengukuran listrik berbahaya tanpa alat yang sesuai dan pengawasan kompeten.
